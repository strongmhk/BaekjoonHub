# 리뷰 순서의 대비 최대화


## 문제 설명

한 주 동안 수집한 `n`개의 풀이 리뷰가 있습니다. 리뷰 `i`를 읽으면 `scores[i]`만큼의 새로운 통찰을 얻습니다. 같은 오개념을 반복해서 다루는 두 리뷰는 함께 선택할 수 없으며, 함께 선택할 수 없는 리뷰 쌍은 `conflicts`로 주어집니다.

정확히 `k`개의 리뷰를 선택해 얻을 수 있는 통찰 점수의 최댓값을 반환하세요. 가능한 선택이 없다면 `-1`을 반환합니다.

### 함수 계약

```text
max_review_insight(scores, conflicts, k) -> integer
```

### 제한사항

- `1 <= n <= 18`
- `1 <= k <= n`
- `1 <= scores[i] <= 100`
- `conflicts`의 각 원소는 서로 다른 인덱스 `[a, b]`이며 중복 쌍은 없습니다.

### 예시 1

```text
scores = [8, 6, 7, 5, 9]
conflicts = [[0, 1], [1, 2], [3, 4]]
k = 3
answer = 24  // 0, 2, 4번 리뷰
```

### 예시 2

```text
scores = [5, 4, 3]
conflicts = [[0, 1], [0, 2], [1, 2]]
k = 2
answer = -1
```

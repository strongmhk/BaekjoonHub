### **피로도를 고려한 계단 학습**

1번부터 `n`번까지 계단이 있고, `fatigue[i]`는 `i + 1`번 계단에 착지할 때 드는 피로도입니다. 지면에서 시작해 한 번에 한 칸 또는 두 칸을 올라 마지막 계단에 도착해야 합니다.

안전을 위해 **두 칸 점프를 연속으로 두 번 사용할 수 없습니다.** 착지한 계단의 피로도 합을 최소화해 반환하세요.

### **함수 계약**

```
minimum_stair_fatigue(fatigue) -> integer
```

- `1 <= fatigue.length <= 100,000`
- `1 <= fatigue[i] <= 10,000`

### **예시**

```
fatigue = [4, 2, 7, 1, 3]
answer = 10
# 1 -> 2 -> 4 -> 5에 착지: 4 + 2 + 1 + 3
```

```
fatigue = [9, 1]
answer = 1
# 지면에서 2번 계단으로 한 번 점프
```

### **제출 전 사고 질문**

1. `i`번 계단까지의 최소 피로도만 저장하면 연속 점프 금지를 판단할 수 있나요?
2. 마지막 이동이 한 칸인지 두 칸인지 상태에 포함하면 전이는 어떻게 달라지나요?
3. 도달 불가능한 상태를 어떤 값으로 표현해야 덧셈이 안전한가요?
4. 전체 DP 배열을 두세 개의 이전 상태만으로 줄일 수 있나요?

### **제출물**

두 DP 상태의 의미, 초기값, 전이식, 마지막 답을 수식과 말로 설명하세요. `n=1`, `n=2`를 직접 추적하고 시간·공간 복잡도를 적으세요.
